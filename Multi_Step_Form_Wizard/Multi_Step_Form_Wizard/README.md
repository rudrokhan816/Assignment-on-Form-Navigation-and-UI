# Multi-Step Form Wizard (Flutter)

A beginner-friendly Flutter project demonstrating a four-step form wizard:

1. Personal Information
2. Contact Details
3. Preferences & Settings
4. Review & Submit

## Features
- Progress bar and step indicator
- Back and Next navigation
- Required-field, email, and phone validation
- Date picker and dropdowns
- Interests checkboxes and notification switches
- Save Draft and restore draft using `shared_preferences`
- Review screen and local demo success screen
- Separated model, screens, widgets, validators, and draft service

## Run on Windows

1. Extract this ZIP.
2. Open the extracted `Multi_Step_Form_Wizard` folder in VS Code.
3. Open Terminal in that folder.
4. Run:

```bash
flutter create .
flutter pub get
flutter run -d chrome
```

To run on a connected Android device or emulator, run `flutter run` instead.

If `flutter create .` asks about overwriting files, choose to keep the existing `lib` source files. This ZIP contains the Dart source and configuration; platform runner folders are generated by Flutter on your machine.

## Draft saving
Draft data is stored locally on the current device/browser using `shared_preferences`. Browser storage is local to that browser profile. It is not synced across devices.

## Submission note
This is a front-end academic demo. Pressing Submit shows a success screen and clears the saved draft; it does **not** send data to a server or create a real account.
